# Md. Farhad Momin, academic website

Personal academic website of Md. Farhad Momin, Lecturer in the Department of Civil Engineering at World University of Bangladesh. The research focuses on seismic assessment of reinforced concrete buildings and machine learning applications in civil engineering.

Live site: https://farhad-momin.github.io/

## Pages

- Research
- Publications
- Teaching
- CV

## Structure

- `_pages/`: page content
- `_publications/`: one file per publication, listed automatically on the Publications page
- `_data/navigation.yml`: header links
- `assets/css/site.css`: site styles
- `images/` and `files/`: images and downloadable files

## Running locally

Install Ruby, Bundler and Node.js, then run:

```
bundle install
bundle exec jekyll serve -l -H localhost
```

The site is then available at http://localhost:4000.
